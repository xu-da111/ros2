## 一、作业要求摘要

在仿真环境中，使用**神经网络**实现感知、规划、控制或端到端算法，并在 GitHub 上完成代码与文档的提交（提交和审核次数均不少于 10 次），否则判为不及格。

### 可选任务（完成前 4 项中任选其一）

| 任务 | 内容 | 分值 |
| ---- | ---- | ---- |
| 任务 1 | 人形/车辆/无人机/水下机器人物理仿真 + 键盘运动控制 | 5 |
| 任务 2 | 传感器感知（雷达/摄像头/深度相机）驱动运动控制 + 给定轨迹控制 | 5×2 |
| 任务 3 | 虚拟环境建图与导航（导航与 SLAM 同步仿真） | 5×3 |
| 任务 4 | 端到端模型（输入图像 → 输出控制指令） | 5×1 |

### 硬性要求

- 感知 / 规划 / 控制 / 端到端算法必须为**神经网络**
- 所有程序必须支持 **launch 启动**，入口为 `main.py` / `main.cpp` 等
- 必须在 **Ubuntu 20.04 + ROS Noetic 或 Humble** 上运行通过
- GitHub **提交次数与审核次数分别不少于 10 次**
- 文档包含 gif 动图演示（推荐 ScreenToGif，一般小于 10MB，不超过 20MB）
- 报告按 **mkdocs 规范**编写，并在 **GitHub Pages** 展示

### 可选仿真环境

OpenHUTB 2.10.0 / CARLA 0.9.16 / AirSim 1.8.1 / HoloOcean 2.3.0 / MuJoCo 3.12.0

## 二、执行计划

1. **环境搭建**：安装 VMware + 下载解压 ROS Noetic/Humble 虚拟机（已完成）
2. **导入虚拟机**：在 VMware 中打开 `ros-noetic-humble-gazebo11-linux-win-v1.vmx`
3. **选定任务**：初步选择 **任务 1（物理仿真 + 键盘运动控制）**，平台待定（地面 / 空域 / 水域 / 人形）
4. **跑通现有示例**：参考仓库 `src/` 与 `docs/` 中已有实现
5. **实现/改进模块**：加入神经网络感知/控制算法
6. **撰写文档**：仿真步骤 + 截图 + 原理公式 + 算法流程 + 源码解析（mkdocs 规范）
7. **录制 gif** 演示效果
8. **GitHub 提交**：分步提交 ≥10 次，每次 PR 找同学审核
